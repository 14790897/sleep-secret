# 看懂报告

报告里的每个数字都来自模型对 3 秒窗口的判定，没有别的输入源。这一页说清楚
它们分别是怎么算的，以及**哪些结论不能从它们推出来**。

## 鼾声指数

> 鼾声时长 ÷ 分析时长 × 100%

跨夜比较用的单一数字。它只统计被判定为鼾声大类的时间，不包括呼吸、咳嗽、环境噪音。

## 睡眠声音评分

100 分往下扣，四项扣完为止：

| 扣分项 | 上限 | 扣满的条件 |
|---|---|---|
| 鼾声占比 | 60 | 鼾声占整夜 **25%** |
| 鼾声连续性 | 15 | 超过 2 分钟的鼾声占鼾声总时长 100% |
| 干扰频次 | 15 | 咳嗽 / 梦话 / 翻身达到 **20 次/小时** |
| 环境噪音 | 10 | 环境声占整夜 **40%** |

总分落在哪一档：

| 分数 | 档位 |
|---|---|
| 85 – 100 | 很安静 |
| 70 – 84 | 比较安静 |
| 55 – 69 | 有些声音 |
| 35 – 54 | 鼾声明显 |
| 0 – 34 | 鼾声很重 |

分析时长不足 **90 分钟**时不给分——太短的录音算出来的「一夜评分」没有参考价值。

!!! warning "这个分数衡量的是「有多吵」，不是「睡得好不好」"

    睡眠分期（深睡 / 浅睡 / REM）和觉醒次数需要加速度计或心率，麦克风测不出来。
    整夜安静但没睡好的人，在这里也会拿到高分。

用扣分制而不是加权平均，是因为加权平均在「整夜只有鼾声」时反而会托底到 40 分左右：
另外三项因为没有其他声音而满分，把重度打鼾的夜晚评得偏高。从 100 往下扣没有这个问题，
而且你可以直接验算：`100 − 60 − 15 = 25`。

## 疑似呼吸暂停的信号

这一栏只有一种声音：**倒吸气**。

它不是「呼吸暂停检测」。它做且只做一件事：把模型整夜里**自己认出来的**那几声倒吸气摆出来，
配时间点和回放，不做任何时序推断。

!!! danger "「听得出声音」不等于「查得出病」"

    一夜里几次倒吸气可能什么都不是，也可能说明气道在做功——麦克风分不清这两者。
    判断是不是呼吸暂停要靠睡眠监测（血氧、气流、胸腹运动），不是一份录音。
    要是打鼾很重、夜里被憋醒过，或者白天老是犯困，带着这份报告去看医生。

    **模型还会把「喘得厉害」也认成倒吸气**（实测 0.68~0.89），
    所以这一栏不专指呼吸暂停之后那一声。

### 为什么只有倒吸气

2026-10-07 用 CC0 素材测过一轮，判据和应用内部完全一致（527 维里取 argmax，
且分数 ≥ 0.5——应用的门槛是 0.25，留了一倍余量）：

| 想要的标签 | 试了几段 | 通过 | 模型实际给的 |
|---|---|---|---|
| `Gasp` 倒吸气 | 4 | **1** | 就是它 |
| `Wheeze` 哮鸣 | 37 | 0 | Screaming / Groan / Cough / Throat clearing |
| `Pant` 喘息 | 40 | 0 | **Gasp** / Breathing / Groan |
| `Snort` 喷鼻息 | 40 | 0 | Oink（猪）/ Sneeze / Horse / Fart |

这不等于证明模型认不出它们：素材是从公共领域录音里搜来的，「Wheeze 1.mp3」未必真是哮鸣，
大半候选根本不是那个声音。准确的说法是**在能找到的 CC0 素材上没能证明它们会响**。

但「没能证明」就够做决定了：这一栏会明确告诉用户我们盯着哪几样，
挂一个证明不了的进去，就是在给「没检出」加一份它没有的可信度。

### 升级前的记录显示「没有收集」

这一栏需要事件里带一个 AudioSet 原始标签名，旧版本不记这个。所以旧记录里
这一栏是空的，但空的原因和「这一夜一个都没认出来」不同——界面上会明说。
分不开的话，你会拿一份**没有数据**的旧报告当作「我一切正常」的证据。

## 详细视图

报告页里点那一行进去，是模型整夜给出的**原始 AudioSet 标签**，按出现次数排序，
带中文对照、归到哪个大类、以及占比。

| 列 | 意思 |
|---|---|
| 次数 | 这个标签当冠军的**窗口数**（一个窗口 3 秒） |
| 英文标签 | 模型的原话 |
| 中文 | 对照翻译，只是补充 |
| 大类 | 我们把它归到哪一类 |
| 未映射 | 527 个标签里只映射了 47 个，其余不属于任何大类 |

它的用处是**分清责任**：报告哪里看着不对时，翻到这一页就能判断是**模型说错了**
（原始标签本身就离谱），还是**我们映射错了**（标签对，但归错了大类）。

「未映射」那一列最值得看：那些标签当冠军的窗口，不产生任何事件，
在报告的其他任何地方都不会露面——只有这一页能看到它们。

!!! note "这一页是模型的原话，不是结论"

    标签没归进大类不代表它不重要，归进去了也不代表判对了。

## 九个大类

| 大类 | 大致包含 |
|---|---|
| 鼾声 | 鼾声、喷鼻息、吸鼻子 |
| 呼吸声 | 呼吸、哮鸣、倒吸气、叹气、喘气 |
| 咳嗽清嗓 | 咳嗽、清嗓 |
| 喷嚏 | 喷嚏 |
| 人声梦话 | 说话、耳语、笑、哭、呻吟 |
| 体动床响 | 翻身摩擦、纸张声、敲击、咔哒 |
| 环境噪音 | 环境噪声、白噪音、车流、风、雨、门、音乐 |
| 设备噪音 | 风扇、空调、电机、充电器嗡鸣、风噪 |
| 静音 | 安静窗口 |

把「设备噪音」单独分出来，唯一理由是**误报**：风扇和空调的低频嗡鸣在频谱上极像鼾声，
是打鼾检测最大的误报来源。混在「环境噪音」里的话，界面只能笼统地说「有环境噪音」，
说不出关键的那句「那是风扇，不是鼾声」。

## 其他几张图

- **整夜声音**：时间线，柱子越高表示事件越突出（鼾声最高，呼吸和环境声最低）。
- **每小时分布**：横轴钟点，纵轴是该小时内声音的总时长。
- **鼾声段时长**：每段鼾声有多长，分成 <15 秒到 >5 分几档。
- **事件明细**：每个事件的时间、类别、置信度；有片段的可以点开试听。
  置信度低的会标出来——0.93 的鼾声和 0.21 的鼾声不该长得一样。
