# Sleep Secret

整夜录音，在手机本地把睡眠中的声音分类，早上给出一份报告：
什么时候有声音、是什么声音、持续多久。

## 三句话

- **默认音频不出设备。** 没有账号、没有服务器，装完就能用。唯一的例外是你
  自己去配置坚果云 / WebDAV，那之后每晚录完传到**你自己名下**的网盘。
- **推理在端侧。** 模型是 CED-tiny（5.5M 参数，AudioSet 预训练），
  转成 ONNX 后在手机上跑，不需要联网。
- **只报模型直接认出来的声音。** 不拿时序去猜「呼吸停了一下」——
  麦克风分不清「呼吸停了」和「呼吸轻到没录到」，这两者的区别要靠血氧和气流。

## 它不做什么

!!! warning "不是医疗器械"

    它不能用于诊断睡眠呼吸暂停或其他疾病。识别结果来自通用的音频事件模型，
    没有针对你本人做过校准。身体不适请就医。

- **不做睡眠分期**（深睡 / 浅睡 / REM）。那需要体动或心率，纯音频做不到。
  这里的「睡眠声音评分」只反映**这一夜有多吵**，不是睡眠质量。
- **不保存整夜原始音频**。8 小时 16kHz 单声道约 920 MB，全存不现实；
  留下的只有事件的时间点和类别，外加你自己选择保留的鼾声片段。

## 只有 Android 和 Windows

手机端是主线。Windows 桌面版能跑，但**只是测试用途**——
桌面没有 Android 那种前台服务保活，整夜录音要求插着电且系统不休眠。

目前没有 iOS 版。
