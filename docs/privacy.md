# 数据与隐私

这个应用的主张是**音频默认不出设备**。这一页把这句话拆开：具体存了什么、
存在哪、什么情况下会离开手机、以及它**保证不了**什么。

## 默认情况下没有任何东西离开设备

- 没有账号，没有登录
- 没有服务器——这个项目没有后端，也不打算有
- 没有统计、崩溃上报、广告 SDK（可以直接去 `app/pubspec.yaml` 看依赖列表核对）
- 分析全部在手机上完成，用的是设备本地的 ONNX 模型

应用代码里唯一会发起网络请求的地方是**你自己配置的**坚果云 / WebDAV 客户端。
没配过，它就不会联网。

## 本地存了什么

一个 SQLite 数据库（`sleep_secret.db`），存的是**分析结果**：

| 表 | 内容 |
|---|---|
| `sessions` | 开始 / 结束时刻、分析时长、窗口计数（总数 / 送进模型 / 跳过 / 低置信度）、事件数、鼾声时长、是否有高危信号数据、原始标签计数 |
| `events` | 每个事件的类别、起始秒、时长、置信度、鼾声概率、最响窗口的音量、以及（鼾声与高危信号的）音频片段路径 |
| `settings` | 应用自己的设置 |

**不存整夜原始音频。** 8 小时 16 kHz 单声道约 920 MB，全存不现实——有意义的
是「什么时候有什么声音」，那用时间戳就够了。

## 音频片段

在「关于」页可以关掉。开着时（默认）：

- 只写**鼾声事件和高危信号**的片段，梦话、咳嗽不写
- 存在应用的私有目录：`<应用数据目录>/clips/<会话开始时刻>/<起始秒>.wav`
- 其他应用**读不到**这个目录（Android 应用私有存储）
- 删除某一晚的记录时，片段跟着一起删；卸载应用时全部清掉

选择私有目录而不是相册或公共音乐目录，是因为睡眠录音属于敏感内容：
不该出现在你随手翻得到的地方，也不该被别的应用读到。

## 唯一的例外：坚果云 / WebDAV

「关于」→「数据导出」里可以填一个 WebDAV 地址（坚果云的话就是
`https://dav.jianguoyun.com/dav/`），之后**每晚录完，应用自己把这一晚传上去**。

- 目标是**你自己名下**的网盘。数据经过的是你的手机 → 网盘的 HTTPS 接口，本项目没有中间服务器。
- 密码请用坚果云的**应用密码**（网页版 → 账户信息 → 安全选项 → 添加应用密码），
  不是登录密码——应用密码可以随时单独吊销，登录密码不能。

!!! warning "凭据存在哪，以及它保证不了什么"

    地址、账号、密码存在应用私有的数据库里（和睡眠数据同一个库）。
    **它不是加密存储**：非 root 的手机上别的应用读不到它，但**拿到这个库文件的人能读出来**。

    这就是为什么要用可随时吊销的应用密码。真在意的话，别在这个应用里配 WebDAV，
    改用下面那种「导出到网盘同步目录」的方式——那种方式应用根本不碰你的网盘凭据。

## 另一种：导出到网盘同步目录

不配 WebDAV 也可以：把导出目录选在 iCloud / OneDrive / 坚果云本地目录里。
这种情况下**应用不联网**，是你电脑或手机上的网盘客户端在同步那些文件。

导出的内容是一样的：一晚一个 JSON（事件时间点、类别、置信度、整晚统计），
加上音频片段（WAV）——**这部分是声音本身**。

## 权限都用在哪

| 权限 | 用途 |
|---|---|
| 麦克风 | 整夜录音。没有它应用什么也做不了 |
| 通知 | 录音期间显示常驻通知；被拒绝不影响录音，但应用更容易被系统清理掉 |
| 前台服务（麦克风型） | 让录音在后台持续运行、不被系统回收 |

没有申请存储权限——导出的目录是通过系统的文件选择器授权的，
应用只能访问你选中的那一个目录。
